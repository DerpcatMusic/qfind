# Megaman

`megaman.svg` is the single master logo used by the GTK app, desktop launcher, and README. The legacy `megaman-logo.svg` and `megaman-logo-dark.svg` paths contain the same artwork. PNG, ICO, and ICNS files are platform exports of this artwork.

Mint `#83BBA8`, deep teal `#203638`, amber `#F5B75C`, and warm white `#E6F3D9`. The artwork uses the repository’s MIT license.
