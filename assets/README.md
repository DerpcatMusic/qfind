# Bit

Bit is Megaman’s voxel file keeper: a folder-shaped mint robot carrying an amber folder. The app is **Megaman**; the mascot is **Bit**.

`megaman.svg` is the master icon. `megaman-logo.svg` and `megaman-logo-dark.svg` pair Bit with an original outlined wordmark; no fonts or external images are required. PNG, ICO, and ICNS files are native app exports of the master icon.

Mint `#83BBA8`, deep teal `#203638`, amber `#F5B75C`, and warm white `#E6F3D9`. Keep the block geometry and transparent background. The artwork uses the repository’s MIT license.
